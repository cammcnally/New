# Overnight file-only pack

This directory is a **file-only** operating model: no reliance on Codex hooks, MCP orchestration, or background schedulers for correctness. **Rules + `AGENTS.md` + repo scripts + a narrow contract** define what “success” means.

## Hardline semantics

**Hardline means instruction-mandatory and contract-validated, not hook-enforced.** Agents should treat [`e2e_contract.json`](e2e_contract.json) and Cursor rules as binding; the repo cannot mechanically stop a bad edit without CI or local discipline. Morning review uses artifacts and `check_e2e_contract.py`.

## Contents

| File | Role |
| ---- | ---- |
| [`e2e_contract.json`](e2e_contract.json) | Machine-readable contract (stages, artifacts, forbidden shortcuts). |
| [`e2e_definition.md`](e2e_definition.md) | Human-readable E2E / DEV-green definitions. |
| [`program.md`](program.md) | Agent-facing loop and invalid-change rules. |
| [`issues.seed.json`](issues.seed.json) | Seed critical-path backlog (`run_repro.py` reads this). |
| [`audit_decision.md`](audit_decision.md) | Template for keep/discard decisions. |
| [`check_e2e_contract.py`](check_e2e_contract.py) | Validate on-disk state vs contract. |
| [`run_repro.py`](run_repro.py) | Print repro hint for an issue id. |
| [`summarize_run.py`](summarize_run.py) | Markdown summary from `out/attempt.json` (optional). |

## Cursor rules (overnight pack)

The overnight instruction pack lives in **four** hand-maintained rules under [`.cursor/rules/`](../../.cursor/rules/):

- `overnight-e2e-repair.mdc`
- `no-fake-e2e-success.mdc`
- `critical-path-priority.mdc`
- `mandatory-root-cause-debugging.mdc`

This repo also contains **additional** `.cursor` files regenerated by `python tools/render_cursor_projection.py` (compatibility shims). Those are **not** part of the minimal overnight layout but coexist with it; do not confuse shim text with the overnight contract.

## Usage

```powershell
uv run python ops/overnight/check_e2e_contract.py --mode dev-green
uv run python ops/overnight/run_repro.py E2E-001
uv run python ops/overnight/summarize_run.py
```

After a real `tools/run_repo_e2e.py --stop-after export_panel` run, `check_e2e_contract.py` should pass for `DEV_EXPORT_SPINE_GREEN` claims.

## Structured outputs

Write per-attempt JSON to `ops/overnight/out/attempt.json` (directory gitignored). Use `audit_decision.md` for human sign-off.
